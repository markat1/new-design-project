# new-design-project

Onboarding-prototyper: tre varianter (stepper, checklist, conversational)
bygget i Blazor WebAssembly, plus enkeltstående HTML-udforskninger af
onboarding- og table-layouts.

## Kør Blazor-prototypen

```
cd proto/BlazorProto
dotnet run
```

De statiske prototyper i `proto/*.html` åbnes direkte i browseren.
